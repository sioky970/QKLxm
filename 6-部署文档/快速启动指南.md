# 快速启动指南 - 5分钟上手

## 🚀 一键启动脚本

### Windows环境

创建 `start-all.bat`:

```batch
@echo off
echo ====================================
echo OKCoinsgp交易所混合架构 启动脚本
echo ====================================
echo.

echo [1/4] 启动MySQL数据库...
net start MySQL80
if errorlevel 1 (
    echo 错误: MySQL启动失败，请检查MySQL服务
    pause
    exit /b 1
)

echo [2/4] 启动Redis缓存...
cd /d "C:\Program Files\Redis"
start redis-server.exe redis.windows.conf

echo [3/4] 启动Go交易后端...
cd /d "d:\工程\交易所源码\OKCoinsgp交易所源码带教程\混合架构版本\1-Go交易后端"
start cmd /k "exchange-go.exe"
timeout /t 3

echo [4/4] 启动PHP管理后台...
cd /d "d:\工程\交易所源码\OKCoinsgp交易所源码带教程\混合架构版本\2-PHP管理后台"
start cmd /k "php artisan serve --host=0.0.0.0 --port=8000"

echo.
echo ====================================
echo 所有服务已启动！
echo ====================================
echo.
echo Go交易后端: http://localhost:8080
echo Swagger文档: http://localhost:8080/swagger/index.html
echo PHP管理后台: http://localhost:8000/admin
echo.
pause
```

### Linux环境

创建 `start-all.sh`:

```bash
#!/bin/bash

echo "===================================="
echo "OKCoinsgp交易所混合架构 启动脚本"
echo "===================================="
echo ""

# 检查MySQL
echo "[1/4] 检查MySQL数据库..."
if ! systemctl is-active --quiet mysql; then
    echo "启动MySQL..."
    sudo systemctl start mysql
fi

# 检查Redis
echo "[2/4] 检查Redis缓存..."
if ! systemctl is-active --quiet redis; then
    echo "启动Redis..."
    sudo systemctl start redis
fi

# 启动Go后端
echo "[3/4] 启动Go交易后端..."
cd "混合架构版本/1-Go交易后端"
nohup ./exchange-go > logs/app.log 2>&1 &
GO_PID=$!
echo "Go后端PID: $GO_PID"

# 等待Go后端启动
sleep 3

# 启动PHP后台
echo "[4/4] 启动PHP管理后台..."
cd "../2-PHP管理后台"
nohup php artisan serve --host=0.0.0.0 --port=8000 > storage/logs/serve.log 2>&1 &
PHP_PID=$!
echo "PHP后台PID: $PHP_PID"

echo ""
echo "===================================="
echo "所有服务已启动！"
echo "===================================="
echo ""
echo "Go交易后端: http://localhost:8080"
echo "Swagger文档: http://localhost:8080/swagger/index.html"
echo "PHP管理后台: http://localhost:8000/admin"
echo ""
echo "Go PID: $GO_PID"
echo "PHP PID: $PHP_PID"
echo ""
echo "停止服务: kill $GO_PID $PHP_PID"
```

## ⚡ 超快部署（5分钟）

### 第一步：数据库初始化（1分钟）

```bash
# 创建数据库
mysql -uroot -p -e "CREATE DATABASE IF NOT EXISTS bibi2022 CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 导入数据
mysql -uroot -p bibi2022 < 混合架构版本/5-数据库脚本/数据库.sql

# 验证
mysql -uroot -p -e "USE bibi2022; SELECT COUNT(*) FROM users;"
```

### 第二步：配置Go后端（1分钟）

```bash
cd 混合架构版本/1-Go交易后端

# 修改配置（使用sed快速替换）
sed -i 's/password: ".*"/password: "你的MySQL密码"/g' config/config.yaml

# 或手动编辑
vim config/config.yaml
```

**关键配置**:
```yaml
database:
  host: "localhost"
  port: 3306
  username: "root"
  password: "root123456"  # ← 修改这里
  database: "bibi2022"
```

### 第三步：配置PHP后台（1分钟）

```bash
cd ../2-PHP管理后台

# 复制配置文件
cp .env.example .env

# 修改配置
vim .env
```

**关键配置**:
```ini
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=bibi2022
DB_USERNAME=root
DB_PASSWORD=root123456  # ← 修改这里
```

```bash
# 安装依赖
composer install --no-dev

# 生成密钥
php artisan key:generate
```

### 第四步：启动服务（2分钟）

```bash
# 启动Go后端
cd ../1-Go交易后端
./exchange-go &

# 启动PHP后台
cd ../2-PHP管理后台
php artisan serve --port=8000 &

# 检查端口
netstat -tuln | grep -E '8080|8000'
```

## 🐛 常见问题快速解决

### 问题1: Go后端启动失败

**错误**: `Error connecting to database`

**解决**:
```bash
# 检查MySQL是否运行
systemctl status mysql  # Linux
net start MySQL80       # Windows

# 检查配置文件
cat config/config.yaml | grep password

# 测试数据库连接
mysql -h 127.0.0.1 -u root -p bibi2022
```

### 问题2: PHP后台报错500

**错误**: `Internal Server Error`

**解决**:
```bash
# 查看错误日志
tail -f storage/logs/laravel.log

# 检查文件权限
chmod -R 755 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache  # Linux

# 清除缓存
php artisan cache:clear
php artisan config:clear
```

### 问题3: 端口被占用

**错误**: `bind: address already in use`

**解决**:
```bash
# 查找占用进程
netstat -tuln | grep 8080  # Linux
netstat -ano | findstr 8080  # Windows

# 杀死进程
kill -9 <PID>           # Linux
taskkill /F /PID <PID>  # Windows

# 或使用其他端口
./exchange-go --port=8081
```

### 问题4: 前端无法连接后端

**错误**: `Network Error` 或 `CORS Error`

**解决**:
```bash
# 1. 检查后端是否运行
curl http://localhost:8080/health

# 2. 检查防火墙
sudo ufw allow 8080/tcp  # Linux
# Windows: 控制面板 -> 防火墙 -> 入站规则 -> 新建规则

# 3. 检查前端API配置
vim 手机前端/src/main.js
# Vue.prototype.$baseurl = 'http://localhost:8080/api'
```

## 📊 服务状态监控

### 一键检查脚本

创建 `check-status.sh`:

```bash
#!/bin/bash

echo "=== 服务状态检查 ==="
echo ""

# 检查MySQL
echo -n "MySQL: "
if systemctl is-active --quiet mysql; then
    echo "✅ 运行中"
else
    echo "❌ 未运行"
fi

# 检查Redis
echo -n "Redis: "
if systemctl is-active --quiet redis; then
    echo "✅ 运行中"
else
    echo "❌ 未运行"
fi

# 检查Go后端
echo -n "Go后端(8080): "
if curl -s http://localhost:8080/health > /dev/null; then
    echo "✅ 运行中"
else
    echo "❌ 未运行"
fi

# 检查PHP后台
echo -n "PHP后台(8000): "
if curl -s -I http://localhost:8000 | grep "200 OK" > /dev/null; then
    echo "✅ 运行中"
else
    echo "❌ 未运行"
fi

echo ""
echo "=== 端口监听 ==="
netstat -tuln | grep -E '3306|6379|8080|8000'

echo ""
echo "=== 进程列表 ==="
ps aux | grep -E 'mysqld|redis|exchange-go|php artisan' | grep -v grep
```

使用:
```bash
chmod +x check-status.sh
./check-status.sh
```

## 🔄 停止所有服务


## 📦 备份与恢复

### 快速备份

```bash
#!/bin/bash
DATE=$(date +%Y%m%d_%H%M%S)
BACKUP_DIR="backup_$DATE"

mkdir -p $BACKUP_DIR

# 备份数据库
mysqldump -uroot -p bibi2022 | gzip > $BACKUP_DIR/database.sql.gz

# 备份配置文件
cp 混合架构版本/1-Go交易后端/config/config.yaml $BACKUP_DIR/
cp 混合架构版本/2-PHP管理后台/.env $BACKUP_DIR/

# 备份上传文件
cp -r 混合架构版本/2-PHP管理后台/public/upload $BACKUP_DIR/

echo "备份完成: $BACKUP_DIR"
```

### 快速恢复

```bash
#!/bin/bash
BACKUP_DIR=$1

if [ -z "$BACKUP_DIR" ]; then
    echo "用法: ./restore.sh backup_20260124_120000"
    exit 1
fi

# 恢复数据库
gunzip < $BACKUP_DIR/database.sql.gz | mysql -uroot -p bibi2022

# 恢复配置
cp $BACKUP_DIR/config.yaml 混合架构版本/1-Go交易后端/config/
cp $BACKUP_DIR/.env 混合架构版本/2-PHP管理后台/

echo "恢复完成"
```
