## ⚠️ 重要提示

### 环境要求
- MySQL 5.7+
- Go 1.16+（如果需要编译运行）
- Python 3.6+（如果使用测试脚本）

### 数据库注意事项
- 确保 `users` 表存在（外键约束需要）
- 数据库名称必须是 `bibi2022`（或修改config.yaml）
- 建议先在测试环境执行

### Token获取
- 所有API测试都需要Token
- 用户Token通过 `/api/login` 获取
- 管理员Token通过 `/api/admin/login` 获取
- Token默认有效期24小时
