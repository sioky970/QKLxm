## 核心API使用

### marketStore.getAllMarketData()
返回所有市场数据的数组，每个元素包含：
```javascript
{
  currency_id: number,
  legal_id: number,
  name: string,        // 币种名称，如 'BTC'
  price: number,       // 当前价格
  change: number,      // 涨跌幅（百分比）
  volume: number,      // 24h成交量
  timestamp: number    // 更新时间戳
}
```

### marketStore.getMarketData(currencyId, legalId)
获取指定币种的市场数据：
```javascript
const btcData = marketStore.getMarketData(1, 1)
// { currency_id: 1, legal_id: 1, name: 'BTC', price: 45678.90, ... }
```

## 使用示例

### 在页面中使用 (示例: index.vue)
```javascript
import marketStore from '@/stores/marketStore.js'

// 使用computed自动响应数据变化
const marketList = computed(() => {
  const allData = marketStore.getAllMarketData()
  
  // 格式化数据供UI使用
  return allData.map(data => ({
    name: data.name,
    price: data.price.toFixed(2),
    change: `${data.change >= 0 ? '+' : ''}${data.change.toFixed(2)}%`,
    volume: formatVolume(data.volume)
  }))
})
```

### 生命周期处理
```javascript
onMounted(() => {
  // ✅ 不需要订阅WebSocket
  // ✅ 不需要fetch数据
  // ✅ 直接使用marketStore即可
})

onUnmounted(() => {
  // ✅ 不需要取消订阅
  // ✅ WebSocket由App.vue统一管理
})
```
